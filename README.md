# ジンバル練習ラボ

DJI RS 5 × Sony α7C II × SIGMA 24-70mm F2.8 DG DN | Art で、イベント（2026/11/14 囲町いけばな神輿まつり）を撮るための練習サイト。

- `index.html` … スマホのセンサーで練習（忍者歩き・水平キープ・なめらかパン・10m総合テスト・会場ウォーク3D）
- `training.html` … 3Dトレーニング（バランス、モード、カメラワーク、当日の通し再生とショットリスト）

センサーは https でのみ動きます（GitHub Pages で公開）。数値はスマホのセンサーからの推定値です。

## ライティング練習ラボ（物撮り）

- `lighting.html` … 反射板やライトがなくても、3Dのスタジオで物撮りの光を練習するページ
  - 光の読み取りクイズ / 実験（予想してから試す） / 見本合わせ（採点は隠して判定3回まで） / 失敗直し（クライアントの言葉から直す） / スマホが反射板（傾きセンサー）
  - ステップ1〜8（光の向き・光の大きさ・白レフ・銀と黒・白背景・逆光の食品・ドリンク・暗い背景）
  - 手持ちの Godox V1 ＋ SGUV6060（60cmソフトボックス）＋ X3 Pro を3Dの道具に反映
- `lighting/engine.js` … 3Dスタジオ（面光源のやわらかい影、反射板・部屋の照り返し、計測と採点）
- `lighting/lessons.js` … カリキュラム
- `lighting/app.js` … 画面と練習モード
